# Active Directory SOC Lab

## Project Overview

This project documents the development of a home Security Operations Centre (SOC) lab using Active Directory, Windows endpoints, and a Linux-based SIEM.

The purpose of the lab is to develop practical cybersecurity skills in:

- Virtualisation
- Windows Server administration
- Active Directory
- Linux administration
- Networking
- Windows event logging
- Security monitoring
- SIEM operation
- Detection and investigation

The project will be documented progressively as the environment is built, configured, tested, and improved.

## Planned Lab Architecture

The lab is planned to include:

- Windows Server acting as an Active Directory Domain Controller
- Windows workstation joined to the Active Directory domain
- Ubuntu Linux server hosting the SIEM
- Centralised collection and analysis of security logs

## Project Status

**Current Phase:** Lab foundation and virtual machine setup.
